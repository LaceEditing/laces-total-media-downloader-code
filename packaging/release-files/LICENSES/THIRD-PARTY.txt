Third-party components in this release
======================================

Lace's Total Media Downloader ships as one self-contained executable. The
components below are bundled inside it. Full licence texts are in this folder.


FFmpeg / ffprobe 7.0.2 — GNU General Public License, version 3
--------------------------------------------------------------
    Static build obtained from https://johnvansickle.com/ffmpeg/
    Configured with --enable-gpl --enable-version3 (includes libx264, libx265).

    Licence text .... ffmpeg-GPLv3.txt
    Build details ... ffmpeg-build-readme.txt
    Source code ..... https://ffmpeg.org/releases/ffmpeg-7.0.2.tar.xz
                      Also available from the build's publisher at the URL above.

    FFmpeg is executed as a separate program by this application. It is not
    linked into it.

    Licence text .... pygame-ce-LGPL-2.1.txt
