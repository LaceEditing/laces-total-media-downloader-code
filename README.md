# Lace's Total Media Downloader

A desktop application for downloading videos and audio from social media platforms and streaming sites.

## What It Does

Downloads videos and audio from popular platforms including YouTube, TikTok, Instagram, Twitter/X, Twitch VODs, SoundCloud, Dailymotion, and 1000+ other sites.

## Features

- Download videos in multiple formats (mp4, mkv, webm, avi, mov, flv)
- Download audio in multiple formats (mp3, m4a, opus, ogg, wav, flac, aac)
- Choose video quality (Best, 1080p, 720p, 480p, 360p)
- Choose audio quality (320, 256, 192, 128 kbps)
- Download entire YouTube playlists or individual videos
- Built-in format conversion (no additional software needed)
- Automatic update notifications

## Download

Get the latest version from the [Releases](https://github.com/LaceEditing/laces-total-media-downloader/releases) page.

No installation required - just download and run the .exe file.

## Usage

1. Paste a video or audio URL
2. Select your format and quality
3. Choose output folder
4. Click Download

## Requirements

- Windows 7 or later
- Internet connection
